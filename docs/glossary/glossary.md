# Glossary

| Term                   | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| Administrator          | A system user with permissions to manage researchers, configurations, and system settings. |
| API                    | Application Programming Interface; enables programmatic access to system data and functionality. |
| Authenticated User     | A user who has successfully logged into the system and can access its features. |
| Bibliometric Metrics   | Quantitative indicators derived from publications, such as citation count, h-index, and i10-index. |
| Dashboard              | A visual interface that presents aggregated data and metrics through charts and tables. |
| External Identifier    | A unique identifier assigned to a researcher in an external platform (e.g., ORCID ID, Google Scholar ID). |
| External Source        | A third-party platform from which publication data is retrieved (e.g., Google Scholar, ORCID). |
| h-index                | A metric that measures both the productivity and citation impact of a researcher’s publications. |
| i10-index              | The number of publications with at least ten citations. |
| LDAP                   | Lightweight Directory Access Protocol; used for authentication and user management. |
| Metric                 | A measurable value representing some aspect of scientific output or impact. |
| Publication            | A scientific work such as an article, conference paper, book, or thesis. |
| Researcher             | An individual author associated with one or more scientific publications. |
| REST API               | An API that follows REST principles, allowing interaction with the system over HTTP. |
| Source Integration     | The process of retrieving and combining data from multiple external platforms. |
| User                   | A general system actor who interacts with the platform. |
